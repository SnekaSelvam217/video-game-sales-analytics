# Video Game Sales & Engagement Analysis (Mini Project)

## Project Overview
Analyze and visualize video game sales and engagement data to identify top-performing games, genres, and platforms. This mini project uses Python, Streamlit, and simple SQL to demonstrate key analytics skills.

## Datasets
- `games.csv`: Game engagement data (ratings, plays, wishlists, etc.)
- `vgsales.csv`: Game sales data (regional and global sales)

## Features
- Top-rated games and genres
- Most wishlisted games
- Best-selling platforms
- Scatter plot: Ratings vs Global Sales

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run Streamlit app: `streamlit run scripts/mini_streamlit_app.py`
3. Open Jupyter notebooks in `notebooks/` for EDA and data cleaning.

## Deliverables
- Cleaned & merged dataset
- Mini Streamlit dashboard
- Jupyter notebooks for data cleaning and EDA
